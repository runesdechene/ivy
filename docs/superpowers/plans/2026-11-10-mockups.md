# Mockups et fichiers d'impression — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dans IVY : régler la taille de chaque motif en le voyant sur des mockups, générer les mockups d'un produit Shopify, les garder, les envoyer sur Shopify, les montrer sur les commandes de stock, écrire les fichiers d'impression dans le dossier du motif, et régler par lot teintes et tailles d'impression.

**Architecture:** Toutes les règles (métachamps, choix du fichier, géométrie, hauteurs, profils de tailles, liste des fichiers d'impression, résolution PNG) sont des fonctions pures testées avec `node --test`. Le montage se fait dans le navigateur sur `<canvas>` ; le dossier du motif s'ouvre en lecture-écriture par `showDirectoryPicker` (Chrome/Edge). Les routes API (service_role, auth Bearer) gèrent tables, Storage et Shopify GraphQL.

**Tech Stack:** Next.js 16 App Router, React 19, Mantine 7, Supabase (Postgres + Storage), Shopify Admin GraphQL `2026-10`, `fflate` (zip).

**Spec:** `docs/superpowers/specs/2026-11-10-mockups.md` — à lire en entier avant toute tâche.

## Global Constraints

- Branche `feat/mockups`. Jamais de push sur `main` ; Uriel déclenche le merge.
- `pnpm` uniquement. TypeScript strict, pas de `any`. Dépendances ajoutées : `fflate`, `@napi-rs/canvas` (révision du 11/11).
- `APP_VERSION` (`src/config/version.ts`, actuellement `0.5.180 - Ivy`) : patch +1 dans chaque commit qui touche `src/`.
- Le dev server tourne peut-être : vérifier avec `pnpm exec tsc --noEmit`, **jamais** `pnpm build`.
- Chaque requête filtre par `shop_id`. Nouvelles routes : `authorizeRequest` + `ownsShop` (`src/lib/hub-ledger/server-auth.ts`) ; côté client `authFetch` (Task 3).
- Shopify : `https://${shop.shopify_url}/admin/api/2026-10/graphql.json`, jeton `shops.shopify_token`. Toute écriture Shopify se teste d'abord sur un produit désigné par Uriel.
- Bucket `mockups` **public** (les images finissent publiques sur Shopify) ; chemins préfixés `${shopId}/`.
- Métachamps de variante, namespace `custom` : `fichier_d_impression` (recto), `verso_impression` (verso), `taille_d_impression`.
- **Cadre maximal d'impression : 49,5 cm de haut × 40,64 cm (16 pouces) de large.** Le cadre d'un gabarit est cette zone sur la photo.
- **Hauteur = hauteur du dessin rogné** (pixels non transparents), jamais de la planche. **Réduction toujours sur la hauteur** ; la largeur suit, rognée au dessin.
- Fichiers sources : PNG 300 dpi, noir ou blanc pur sur fond transparent ; ils ne donnent que la forme, la couleur vient du réglage de la teinte. Pas de mode produit.
- Dossier d'un motif : `<MOTIF> CLAIR.png`, `<MOTIF> SOMBRE.png`, `<MOTIF> MARQUE.png`, et facultativement `<MOTIF> DTF.png` (sinon le logo DTF commun des Réglages).
- Marque et DTF : taille réelle (300 dpi), une seule taille, posés au **point poitrine** du gabarit. DTF = recto des vestes zippées uniquement.
- Constantes : `CADRE_HAUTEUR_CM = 49.5`, `CADRE_LARGEUR_CM = 40.64`, `PX_PAR_CM_300DPI = 300 / 2.54`, `OPACITE_ENCRE = 0.75`, `PX_PAR_METRE_300DPI = 11811`.
- Teintes (couleur + version) et logo DTF commun = réglages en base ; hauteurs = fiche du motif en base. Jamais de constantes.
- Avant d'écraser un fichier dans le dossier du motif : confirmation listant les fichiers concernés.
- UI en français, mise en page des nœuds Figma `1:2` et `2:2` (skill `figma:figma-design-to-code` avant `get_design_context`), composants Mantine, styles calqués sur `src/app/ivy/inventaire/logistique/page.tsx`.
- Fichiers testés par `node --test` : imports relatifs avec extension `.ts`, pas d'alias `@/` (convention de `src/lib/hub-ledger/pin.test.ts`).

## Review Focus

1. Fichier source absent (CLAIR, SOMBRE, MARQUE) → « fichier manquant », exclu du zip, de l'envoi et des fichiers d'impression ; rien ne plante (Task 2).
2. Teinte non réglée ou motif sans hauteur pour la taille demandée → « teinte à régler » / « hauteur à régler », jamais une valeur inventée (Task 2).
3. Hauteur qui ferait dépasser 40,64 cm de large (motif paysage) → plafonnée par `hauteurMax`, l'éditeur ne peut pas la dépasser (Task 2, Task 6).
4. Échec en cours d'envoi Shopify → les anciens médias restent : on ne supprime qu'en dernier ; médias en traitement → 409 et nouvel essai (Task 8).
5. Fichiers d'impression sans résolution → lus en 72 dpi par l'imprimeur : test du bloc `pHYs` (Task 2), contrôle dans un logiciel d'image (Task 11).

```sql
CREATE TABLE IF NOT EXISTS mockup_gabarits (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  shop_id UUID NOT NULL REFERENCES shops(id) ON DELETE CASCADE,
  modele TEXT NOT NULL,            -- SKU Shopify exact, ex. 'DRUMMER 2.0'
  couleur TEXT NOT NULL,           -- option « Couleur » Shopify, ex. 'Noir'
  face TEXT NOT NULL CHECK (face IN ('recto', 'verso')),
  photo_path TEXT NOT NULL,
  ombres_clair_path TEXT,
  ombres_sombre_path TEXT,
  cadre_x REAL NOT NULL, cadre_y REAL NOT NULL, cadre_hauteur REAL NOT NULL,  -- px sur la photo ; hauteur = 49,5 cm
  poitrine_x REAL, poitrine_y REAL,  -- haut-centre de la marque ou du logo DTF, recto seulement
  created_at TIMESTAMPTZ DEFAULT NOW(), updated_at TIMESTAMPTZ DEFAULT NOW(),
  UNIQUE (shop_id, modele, couleur, face)
);
CREATE TABLE IF NOT EXISTS mockups (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  shop_id UUID NOT NULL REFERENCES shops(id) ON DELETE CASCADE,
  product_id UUID NOT NULL REFERENCES products(id) ON DELETE CASCADE,
  couleur TEXT NOT NULL,
  face TEXT NOT NULL CHECK (face IN ('recto', 'verso')),
  image_path TEXT NOT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW(), updated_at TIMESTAMPTZ DEFAULT NOW(),
  UNIQUE (shop_id, product_id, couleur, face)
);
CREATE INDEX IF NOT EXISTS idx_mockups_product ON mockups(product_id);
CREATE TABLE IF NOT EXISTS mockup_reglages (     -- une ligne par boutique
  shop_id UUID PRIMARY KEY REFERENCES shops(id) ON DELETE CASCADE,
  teintes JSONB NOT NULL DEFAULT '{}',          -- { "CUI": { "couleur": "#c9b79c", "version": "SOMBRE" }, … }
  dtf_path TEXT,                                -- logo DTF commun
  updated_at TIMESTAMPTZ DEFAULT NOW()
);
CREATE TABLE IF NOT EXISTS mockup_motifs (       -- fiche d'un motif
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  shop_id UUID NOT NULL REFERENCES shops(id) ON DELETE CASCADE,
  nom TEXT NOT NULL,                            -- nom du dossier, en majuscules, ex. 'LOKI'
  hauteurs JSONB NOT NULL DEFAULT '{}',         -- cm de dessin : { "A-SMALL": 38.1, …, "D-MAX": 45.7 }
  updated_at TIMESTAMPTZ DEFAULT NOW(),
  UNIQUE (shop_id, nom)
);
CREATE TABLE IF NOT EXISTS mockup_profils (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  shop_id UUID NOT NULL REFERENCES shops(id) ON DELETE CASCADE,
  modele TEXT NOT NULL,
  nom TEXT NOT NULL,
  grille JSONB NOT NULL,                        -- { "XS": "B-MEDIUM", "S": "C-LARGE", "M": "D-MAX", … }
  created_at TIMESTAMPTZ DEFAULT NOW(),
  UNIQUE (shop_id, modele, nom)
);
```
